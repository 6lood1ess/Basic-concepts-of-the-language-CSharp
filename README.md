# Laboratory work: Basic concepts of the language CSharp

## Author
Zaharov Nikita

## Goal
Mastering the basic concepts and syntax of CSharp in practice.

## Description
The program has two tasks: 
1. Construction of the number into n exponent
2. Moving digit of the number x from the second to the last

## Source data
The user enters through the console either the base degree and exponent, or the number whose second digit needs to be moved.

## Expected results
The program outputs either the result of the construction in exponent or transformed number.
